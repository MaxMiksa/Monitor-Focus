# 界面设计

## 设计方向

项目采用 A「随手调节」：逐屏亮度与色温优先，场景作为快捷入口，时间计划和专注规则放在设置页。目标是现代、直接、轻量的 Windows 控制面板，而不是功能展示页。

视觉参考保存在 [`design/candidates/controls-first.png`](design/candidates/controls-first.png)。未采用的方案仍作为[历史候选](design/candidates/scenes-first.png)保留，但不指导当前界面。

设计核对必须基于真实界面截图。生成图只定义方向，不能证明设备能力、写入成功、曲线计算或验收完成。

## 信息结构

| 页面 | 主要任务 |
| --- | --- |
| 快捷面板 | 查看双屏状态，调亮度和色温，切换场景，暂停专注 |
| 时间计划 | 添加时间节点、选择场景、设置渐变并调整顺序 |
| 场景 | 管理场景名称、逐屏目标与保存顺序 |
| 专注 | 设置专注开关、等待时间、受控副屏和全屏例外 |
| 通用 | 设置界面语言、登录自启及顶部亮度／底部音量滚轮开关 |

主路径是打开面板、完成日常调节、关闭面板。设置页承担低频规则维护，不把复杂编辑放进快捷面板。

## 布局原则

- 快捷面板首屏优先显示两块屏的名称、亮度和色温。
- 设置页固定左侧菜单和底部保存栏，只有右侧内容区滚动。
- 切换设置页时回到内容顶部，同时保留共享草稿。
- 错误、预览和保存结果提示常驻可见，不随内容滚出视口。
- 排序列表建立自己的定位容器，避免隐藏播报元素撑高外层文档，造成第二条滚动条。
- 内容在 1040、800、680 三种宽度下保持可操作，不出现水平溢出。

## 视觉基础

唯一参数入口为 `src/MonitorsFocus.Web/src/index.css`。页面引用共享角色，不自行增加颜色、字号、圆角或动效数值。

| 项目 | 规则 |
| --- | --- |
| 字体 | Segoe UI Variable / Segoe UI / Microsoft YaHei UI，全部无衬线 |
| 字号 | 只使用 14 / 16 / 24 DIP，分别用于辅助、正文与操作、标题与重点数值 |
| 字重 | 400 / 500 / 600，通过字重和位置建立层级 |
| 间距 | 4 DIP 基础单位；常用 8 / 12 / 16 / 24 / 28；2 DIP 只作集中校正 |
| 颜色 | 低饱和浅灰画布、白色操作面、深灰文本、蓝色主操作；状态同时提供文字 |
| 控件高度 | 主要操作控件最小 40 DIP，保留清晰焦点和可访问名称 |
| 圆角 | 矩形控件和表面使用 `corner-shape: superellipse(2)`；控件曲率范围 12，表面范围 20 |
| 基本几何 | 滑条轨道和圆形滑块保留功能几何；系统窗口外框由 Windows 绘制 |
| 动效 | 操作反馈和局部切换 150 ms；尊重系统“减少动态效果”设置 |

颜色、背景和控件始终在同一主题下渲染。不同 DPI 使用逻辑尺寸，不把窗口物理像素直接当作设计尺寸。

## 共享组件

| 组件 | 规则 |
| --- | --- |
| 文字 | 使用统一字体和三级字号；数字右对齐，数值变化不推动标签 |
| 操作按钮 | shadcn Button 统一主次、悬停、焦点、按下和禁用状态；Lucide 提供功能图标 |
| 显示器调节行 | 名称、目标值、滑条、能力和错误；支持键盘方向键，失败时保留重试入口 |
| 色温调节 | 位于对应亮度下方，共用五列表格与滑轨宽度；只在右侧显示温度和图标 |
| 亮度联动 | 使用连接／断开图标，不用文字开关或状态胶囊；反映真实状态和 `aria-pressed`；有设备曲线时提示“校准联动”，否则提示“保持比例” |
| 表单 | 同角色统一高度、内边距和连续轮廓；保存失败时保留输入 |
| 场景编辑 | 展示名称和逐屏目标；删除位于名称行右侧，拖动手柄与设备图标居中对齐 |
| 时间计划 | 输入和曲线使用同一计算规则；列表顺序与时间值分离 |
| 排序手柄 | 时间点和场景共用；提供拖动插入线及聚焦后的上下方向键移动 |

Web 组件由项目维护，不套用 shadcn 默认模板视觉。Motion 只用于短反馈，Lucide 统一图标语义。

## 内容与状态

- 不显示灰色辅助说明、功能定义或重复图注。
- 保留错误、保存结果、当前来源、连接和检测状态、预览标识、单位和图表刻度。
- 场景禁删原因只在按钮悬停提示中说明，不占常驻空间。
- 滑条在请求失败后回到真实目标，不把失败值留在界面上。
- 页面刷新或状态推送不抢焦点，不重置正在编辑的输入。
- 设置页切换保留草稿；重新载入放弃草稿并恢复已保存设置。

## 快捷面板

- 两块屏的亮度行优先，数值和滑条形成稳定的横向基线。
- 核心报告可调色温的屏幕在亮度下方显示色温行，外接屏与内屏共用同一控件；没有能力时不保留空行。K 值表示近似冷暖，较暖端可能受系统调色范围限制。
- 已校准内屏的亮度滑条仍显示用户目标；自动补光不推高滑条数值，不改变主屏。背光达到上限时复用现有警告区说明无法完全补偿，不禁用调节。
- 场景入口与来源区并排，来源区区分手动场景和时间计划。
- 快捷面板保留恢复原色入口；场景编辑不占用滑轨宽度放置该操作。
- 专注暂停和设置入口位于底部固定操作区。

## 设置页

- 左侧菜单使用蓝色文字、浅蓝底和左标记表示当前页。
- 右侧内容首屏说明当前任务；底部保存操作栏独立占位，不遮挡最后一项内容。
- 场景页底栏依次为撤销、重做、“重置”和“保存”，只有“保存”使用蓝色主操作。
- 时间计划和场景的排序都先修改草稿；保存后持久化，取消拖动保留原顺序。
- 任何页面都不得因局部图表或隐藏元素产生双滚动条。
- 通用页在登录自启下方依次放置“顶部滚轮调节亮度”“底部滚轮调节音量”，复用带关联标签的 Switch 行；独立编辑、默认关闭，使用现有保存／还原与共享草稿，不新增弹窗或说明小字。
- 两个滚轮开关下增加“色温／应用音量按键”，复用现有带关联标签的 select 行，可选 Alt、Ctrl、Shift，默认 Alt；共用现有草稿、保存和还原，不增加快捷键录制窗口。
- 普通边缘滚轮保留 Windows 原生亮度／音量浮层；亮度提示采用用户确认的内屏系统背光值。
- 增强模式复用一个按需创建的原生绘制小窗，沿用用户确认的圆角胶囊参考。图标、名称、数值占首行，下方显示进度；色温轨道从暖橙到冷蓝，应用音量用蓝色，只显示一个与应用合成器刻度对应的百分比及全静音标记。输入时立即更新目标进度，后台完成后校正；软件起始音量未知时显示“…”和空轨道，不虚构百分比；失败隐藏并提示，旧确认不能覆盖更新的输入。跟随系统深浅色及高对比度，按所在屏 DPI 缩放，在工作区底部居中；不抢焦点、鼠标穿透，停滚约 1.5 秒后隐藏，迟到的确认不重新弹出。无需 WebView、新进程、图片纹理或持续动画。

## 设计验收

每次界面改动至少检查：

- 页面层级、主要任务和首屏信息是否仍清楚。
- 字体档位、控件高度、间距、颜色和连续曲率是否引用共享参数。
- 键盘焦点、错误、加载、离线、等待和保存失败状态是否可见。
- 设置页是否只有内容区滚动，错误提示和底部保存栏是否常驻。
- 中英文切换后，长文本、无障碍名称和可操作区域是否完整。
- 实际截图是否与当前界面一致；过时截图不得作为当前证据。

当前验证结果和截图状态见[验收说明](ACCEPTANCE.md)。
