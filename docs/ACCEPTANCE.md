## 边缘滚轮实机复验

当前即时预览／异步调节版已正常重启，两个已有开关保持开启；全新配置才默认关闭。输入时立即更新目标进度，实际调节完成后校正；首次软件起始音量未知时不虚构数值，失败清除预览。基础调节已由用户确认，原生浮层已单独唤起并实拍，两个原生测试会话的统一音量及隔离、轻量浮层窗口／资源检查沿用此前结果；新增预测与校正逻辑检查通过，真实手感待复验。剩余按以下顺序复验：

1. 各屏顶部／底部上下滚动，确认亮度／当前默认播放音量每格变化 2%，到 0／100% 后不越界。
2. 关闭联动只改鼠标所在屏；开启联动使用已有设备曲线；手动亮度保持到下一计划节点。
3. 离开边缘一行、按住未选按键／Win、多个修饰键组合（含 AltGr）、拖拽及水平滚轮均保留原行为；边缘触发不同时滚动窗口。默认仅 Alt 触发增强模式。
4. 两个开关分别关闭并保存后立即停止接管；关闭面板仍可用。确认快速滚动不卡鼠标，设备失败有真实错误反馈。
5. 检查混合 DPI、负坐标、上下排列屏幕、任务栏自动隐藏、全屏、热插拔和休眠恢复；重检期间不接受旧屏幕请求。
6. 切换耳机／扬声器后调整新的默认输出，原静音状态保持；无播放设备时显示失败。后台会话、锁屏及正常退出后不残留接管。
7. 顶部出现系统亮度浮层，显示内屏背光；底部出现系统音量浮层。连续滚动保持更新，到 0／100% 仍可提示；硬件失败时不显示成功提示。计划和面板滑块不触发本功能的浮层。
8. 增强按键 + 顶部每格 100 K，上滚更冷、下滚更暖；关闭联动仅调整鼠标屏，开启后同步支持调色的屏幕，限制在 2700–6500 K；色温不支持时放行滚轮，沿用手动保持。
9. 增强按键 + 底部仅调前台软件音量，每格 2%，多个匹配会话统一为同一百分比，浮层只显示该数值和进度；对照 Windows 合成器检查 50% 对应关系，保持静音和系统总音量。鼠标在其他屏／其他窗口上仍以焦点软件为准。浏览器播放音频时覆盖同一进程树的音频进程，独立实例不串改；无会话时提示，切换焦点后旧请求停止。
10. 增强模式显示鼠标所在屏底部的轻量数值／进度条，不弹系统亮度／总音量浮层；输入时进度立即响应，后台调节完成后校正，旧确认不拉回新输入，首次软件音量未知显示“…”等待真实读数，错误清掉预览并提示。色温显示 K 值和暖→冷进度，不抢焦点、鼠标穿透，停滚约 1.5 秒后隐藏，迟到的确认不重新弹出。增强模式切换和前台窗口切换不继承高精度滚轮余量。独立应用输出路由、多个会话、部分设备失败和独占音频需单独核对。
11. 通用设置依次选择 Alt、Ctrl、Shift 并保存，仅所选单键触发增强模式；换键后旧队列／余量失效。未保存时仍用原按键；还原恢复已保存值；关闭并重开面板、重启核心后保留选择。真实按键手势及本次应用音量连续滚动的手感尚待用户复验。

基础调节的用户确认和单独浮层实拍不替代以上完整边界复验。

## 复验顺序

代码或界面改动后，根据风险执行：

1. `pnpm --dir src/MonitorsFocus.Web run lint`
2. `./scripts/build.ps1`
3. `dotnet run --project tests/MonitorsFocus.Tests -c Release --no-build`
4. 运行 WebHost，完成受影响页面的交互检查。
5. 涉及硬件时补做真实亮度、色温、恢复、休眠和热插拔检查，并更新本文件。
