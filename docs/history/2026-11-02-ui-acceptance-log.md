中英文验收截图：[英文快捷面板](../design/acceptance/i18n-quick-en.png)、[英文通用页](../design/acceptance/i18n-general-en.png)、[中文通用页](../design/acceptance/i18n-general-zh.png)。使用模拟桥，不连接硬件；截图中的用户场景名称保留中文属于预期行为。语言选择即时预览，保存后同步托盘并跨启动保留；英文色温标签按内容宽度布局，操作区允许换行，沿用原有字号与组件。

合理差异：已移除全部应用快捷键及旧版热键设置，通过面板或托盘暂停、恢复专注；场景快捷键取消需求。内屏不调色；色温仅硬件、数值为近似值。计划在节点后按 smoothstep 缓入缓出，新增节点默认30分钟，可设数小时且须在下一节点前完成；图表使用相同规则，原色按6500 K基线参与预览。没有计划时保留图表坐标和添加时间点入口，不显示灰色预览说明。曲线预览当前编辑草稿，不会自动保存或写入设备。亮度数值为正常亮度目标，硬件写入完成/读回状态尚需进一步细分，不能据此宣称全部硬件行为已验收。本轮两项移除已打包更新至本机并重启，构建、lint及35项自动检查通过；未进行交互复验。

界面验收时检查：Web类型检查和生产构建、Oxlint、解决方案Release构建（0警告0错误）、7项假设备检查通过；生产npm依赖审计未报告漏洞。原npm镜像不支持审计，已改用官方registry完成该次审计，未更改用户全局配置。2026-11-01修复后，解决方案Release构建及扩充后的12项自动检查通过，覆盖正常亮度变化后的退出恢复、色温延迟探测恢复和旧配置迁移；真实休眠重连仍待验收。2026-11-01四项功能集成后，完整35项检查、双语页面及组合交互通过；集成截图和修复详见[验收矩阵](2026-11-01-integration-acceptance.md)。

资源观察为一次瞬时样本：关闭前宿主工作集约83MiB，6个本应用WebView2进程工作集各约18–142MiB；关闭后它们均退出，核心工作集约64MiB。各进程工作集有共享页，不能直接相加当物理占用，也不代表长时间低占用验收。

待用户体验与后续验收：真实双屏手动写入、比例绑定、外屏色温能力稳定性和恢复、计划长时间运行、休眠/热插拔、混合DPI。v2.0.0 已发布，上述项仍未验收。
