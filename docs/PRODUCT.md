# 产品说明

## 定位与范围

Monitors Focus 是面向个人使用、兼顾开源分享的 Windows 显示器控制中心。Go 常驻核心负责硬件、计划、专注和边缘滚轮；React 面板按需打开，关闭后核心继续运行，不保留自有 WebView2 界面进程。

- 支持 Windows 10/11 x64 与 Microsoft Edge WebView2 Runtime。
- 主要真机环境是一块 AOC U27G4 外接屏和一块 BOE 笔记本内屏；外接屏用 DDC/CI，内屏用 WMI 调背光。
- 色温面向兼容 SDR 屏幕，通过逐屏 GDI Gamma 调色，不叠加硬件 RGB 调色。
- 不提供 HDR 色温、ICC 色彩管理、应用快捷键或场景快捷键。`2700–6500 K` 是近似冷暖标尺，较暖端受系统 Gamma 范围限制，不代表仪器测量值。

控制只面向前台物理控制台会话中已确认稳定身份的实体屏幕。会话切换、设备映射变化或身份不明时停止写入并等待重新检测；不切换到 RDP 桌面控制其颜色。后台采集画面的像素隔离仍需实机验收。

## 概念与状态

- **正常目标**：面板、场景或时间计划希望屏幕达到的亮度和色温；界面百分比表示正常亮度目标。
- **手动保持**：手动调节后，目标保持到下一计划节点。实时到达节点时从当前目标继续渐变，不跳回旧值。
- **场景**：保存逐屏目标、亮度联动与专注规则的命名组合。
- **时间计划**：按本地时间节点应用场景，并以 `smoothstep` 缓入缓出到下一目标。
- **专注遮罩**：鼠标离开受控副屏达到延迟后覆盖副屏，不改变硬件亮度或正常目标。

面板分别显示检测中、离线、设备错误和保存状态；硬件失败不能显示为成功。当前界面尚未完整区分「目标值 / 写入中 / 硬件读回」。

## 快捷面板

- 逐屏显示亮度目标和能力；可调色温的屏幕在亮度下方增加色温滑条，无能力时隐藏该行。
- 连接／断开图标切换亮度联动，并标明「校准联动」或「保持比例」。快捷面板可切换场景、暂停或恢复专注、恢复原色和进入设置。
- 来源区区分手动场景与时间计划；场景入口沿用设置页顺序。
- 设置页固定左侧导航和底部保存栏，只有右侧内容滚动。切换页面保留共享草稿并回到顶部。

手动调节立即生效；失败时滑条回到真实目标，保留重试入口和错误文字。场景、计划、专注、语言和通用开关均在设置页编辑，点击保存后才持久化。

## 亮度与颜色

### 逐屏亮度

每块已识别屏幕按各自能力写背光，命令通过串行通道执行。亮度联动开启时，已校准设备对使用按稳定设备标识保存的单调分段曲线，双向插值；未校准设备沿用比例绑定。缺少配对设备时只调整当前屏，不把曲线套到其他屏幕。

当前 `calibrations/aoc-boe-brightness.json` 是本机 AOC/BOE 的个人观感匹配数据：外屏 0% 对应内屏 25%，外屏 95% 以上时内屏保持 100%。按用户决定，同一曲线暂用于所有色温；暖色下未测得独立匹配曲线，不承诺跨色温等亮。个人数据不写入程序默认值。

### Gamma 颜色所有权

- 首次实际调色前保存完整原始颜色表，写入后读回验证；6500 K、恢复原色和正常退出时恢复本应用仍持有的调整。
- HDR、高级颜色、复制显示或 CCD 映射无法确认单一目标时拒绝调色；写入前再次核对前台会话和稳定设备身份。
- 约每 3 秒核对暖色目标：仅退回本应用保存的原色基线时重新应用；检测到其他程序写入的未知颜色时停止调色并提示重新检测，不覆盖外部新设置。
- 恢复记录用颜色 journal 保存到正式配置目录；仅当当前表仍等于本应用最后写入的表时恢复，失败时保留 journal 供后续处理。
- 读回一致仅证明颜色表状态，不能代替真实画面观察。与其他调色软件、夜间模式或游戏同时使用可能冲突。

### 内屏暖色补光

色温变暖会降低白色亮度。只有身份已确认、非主屏、已完成个人校准且当前颜色由本应用持有的内屏可以补光；外接屏不补光。用户正常亮度目标与实际背光目标分开保存，补光不回写滑条或场景权重。

校准按稳定设备标识保存至少两档参考亮度和两个暖度的主观匹配点，范围内插值，超出范围保守延伸。背光到 100% 时提示无法完全补偿，不减弱用户选择的暖度。恢复原色、调色失败、失去颜色所有权或正常退出时先撤回补光；未经校准时不启用。当前本机尚未完成暖色补光校准，跨屏曲线与补偿数据互相独立。

## 场景

场景保存逐屏正常亮度、色温、亮度联动开关、比例权重、专注开关和受控副屏。设备曲线和补光校准独立保存，不随场景复制。

- 默认控制全部副屏；显式空选择表示不控制任何副屏，不等于「全部」。主屏始终排除。
- 离线设备的目标和受控标识按稳定 ID 保留，不映射到其他屏幕。
- 手动切换和计划节点使用同一套场景行为。旧场景缺少行为字段时继承加载时的当前规则，读取不会改写用户文件。
- 新场景捕获当前正常目标与规则，不保存临时遮罩状态。被计划引用的场景不能删除，原因只在按钮悬停提示中说明。
- 场景页可编辑名称与逐屏目标、拖动排序或用键盘移动；撤销、重做、重置和保存作用于草稿。保存后同步快捷面板顺序，保存失败保留草稿和历史。当前页面不展示绑定、专注及受控副屏编辑区，已有规则仍保留。

## 每日计划

每个节点包含时间、场景和渐变分钟数，默认 30 分钟，`smoothstep` 缓入缓出，0 分钟立即切换，终点不能越过下一节点。跨午夜连续求值；休眠或启动时错过节点按当前时刻直接求值，不补播历史步骤。

进入新节点时只应用一次场景行为并重置专注计时，渐变期间不反复重置。语言、专注暂停状态、场景名称、列表顺序等无关保存不重播节点，也不清除手动保持；修改计划或所引用场景会重新应用相关规则。时间点和场景支持拖动及聚焦手柄后上下方向键移动；列表顺序与执行时间分离。

## 专注

专注只控制副屏遮罩，不改变亮度。鼠标离开受控副屏达到设定等待时间后显示遮罩；鼠标返回、暂停或副屏存在符合条件的全屏／最大化窗口时隐藏。窗口检测覆盖所有顶层窗口，不限于前台；排除最小化、隐藏、其他虚拟桌面和本应用遮罩。最后一个占用窗口结束后重新计算完整等待时间。

桌面状态读取失败时撤下遮罩、丢弃旧坐标并暂停判断；恢复后清除专属提示并重新计时，不沿用未知鼠标位置，也不清除其他错误。该选项只影响遮罩，不修改 Windows 电源或睡眠超时。

## 屏幕边缘滚轮

顶部和底部滚轮各有一个独立开关，默认关闭，保存后生效，关闭面板仍可用。鼠标位于任一屏幕最顶／最底一行像素时，真实垂直滚轮上滚增加、下滚减少；每格 2 个百分点，高精度滚轮按 120 单位累积。仅接管无鼠标按键、无其他修饰键或只按所选增强键的输入；离开边缘、停顿超过 500 ms、换屏／换边缘／切换增强模式／切换前台应用后清除余量。注入输入、水平滚轮和后台会话放行；触发后不再滚动下方窗口。

- **顶部普通模式**：调鼠标所在屏的正常亮度，遵循联动、校准、补光和手动保持；完成后唤起 Windows 原生亮度浮层，浮层显示系统内屏背光，不映射外屏或补偿前目标。
- **底部普通模式**：每次重新获取当前默认播放设备的主音量，保留静音；完成后唤起系统原生音量浮层。
- **增强顶部**：每格调 100 K（2700–6500 K，上滚更冷）；联动开启时同步支持调色的屏幕，调色失败单独报告。
- **增强底部**：按前台窗口归属调整软件音频会话，每格 2%，多会话统一到一个百分比并保留静音；不改系统总音量，也不回退到主音量。焦点切换后旧请求停止；独占音频、归属不明确或仅由其他宿主代播的窗口不保证支持。

增强按键默认 Alt，可在「设置 → 通用」选择 Alt、Ctrl 或 Shift，保存后生效；换键使旧队列和余量失效。增强模式复用一个按需创建的原生胶囊浮层，显示色温或应用音量读数与进度；鼠标穿透、不抢焦点，停滚约 1.5 秒隐藏。没有可控会话时隐藏数值条，使用限频托盘通知提示先播放音频；不把缺失会话伪装成 0%。普通边缘滚轮不显示增强浮层，计划和面板滑条不触发原生浮层。

## 语言、启动与退出

- 支持简体中文、English 和跟随系统；切换语言立即预览但不重建草稿，保存后面板即时生效。中文系统语言（含繁体）使用简体中文，其他语言回退 English。用户改名的场景保持原样，默认场景名称可随语言变化；前端偏好在加载首屏时读取，保存后用于后续启动。当前托盘菜单固定使用中文。
- 登录自启只保留 `HKCU` 下唯一 `MonitorsFocus` 项，命令指向正式包中的 `MonitorsFocus.Go.exe --mode native --hardware --production --background`。配置读取、迁移或核心初始化失败时不改动已有自启项。
- 关闭面板销毁 WebView2，再次打开由现有核心按需创建窗口；正式构建无参数打开面板，`--background` 只启动托盘。正常退出移除遮罩、卸载滚轮钩子、撤回补光并恢复原色，保留最新正常亮度。

## 设置保存与失败恢复

- 配置保存到 `%LOCALAPPDATA%/Monitors-Focus-Go/native-settings.json`，颜色恢复记录在同目录；保存前检查 Revision，冲突时旧草稿保留并提示重新载入，不能覆盖新设置。
- 原子写入保留上一版 `.bak`，保存失败保留草稿和 Revision；坏文件、未知 schema 或读取权限错误不允许用默认值覆盖。显式迁移会备份旧配置并保留原文件，不自动改写登录自启。
- 重新检测按稳定标识保留本次会话的色温目标；先恢复原色基线，再应用用户目标。断开设备的目标保留到核心退出。无关设置保存不会让手动保持提前结束。

## 界面设计准则

产品方向是「随手调节」：快捷面板首屏突出双屏亮度和色温，场景是快捷入口，低频规则放进设置页。生成图只定义方向，界面核对必须使用与当前源码一致的真实截图，不得用旧图证明当前状态。

- `frontend/src/index.css` 是唯一设计参数入口；页面不自行新增颜色、字号、圆角或动效数值。字体使用 Segoe UI Variable / Segoe UI / Microsoft YaHei UI，字号为 14 / 16 / 24 DIP，间距以 4 DIP 为基础，主操作控件最小高度 40 DIP。
- 低饱和浅灰画布、白色操作面、深灰文字和蓝色主操作；状态同时提供文字。统一使用 shadcn 风格按钮、表单和滑条，Lucide 图标、Motion 短反馈；圆角使用 `corner-shape: superellipse(2)`，尊重系统减少动态效果。
- 数字右对齐，滑条支持键盘方向键；亮度联动使用连接／断开图标并反映 `aria-pressed`。错误、保存结果、来源、检测与连接状态常驻可见。页面刷新或状态推送不抢焦点、不重置输入。
- 在 1040、800、680 DIP 宽度下保持可操作，无水平溢出或双滚动条；隐藏播报元素放在自己的定位容器中。中英文切换后检查长文本、无障碍名称和可操作区域。
- 不显示灰色小字解释、功能定义或重复图注；输入、预览、保存失败和错误状态仍须清楚。
- 品牌图形为「双屏 + 亮度」，主色 `#125cd0`。修改图标几何时同步更新 `frontend/public/app.ico` 和 `frontend/public/favicon.svg`；exe、窗口与托盘共用当前应用图标。

## 已知边界

- 面板百分比是目标值；目标、写入中、硬件读回的完整区分尚未实现。
- 当前场景页精简、固定设置菜单与保存栏缺少针对最新工程的交互复验。
- 真实比例写入与触顶恢复、休眠重连、热插拔、混合 DPI、HDR、真实 RDP 捕获画面隔离、长时间运行、任意崩溃或断电后的颜色恢复，仍需在对应环境验收。
- 暖色下的跨屏观感一致性、内屏补光启用与完整范围恒亮未验收；用户反馈的内屏轻微偏绿尚未确定发生条件和修正量，当前没有自动校正独立颜色通道。
- 软件音量对真实浏览器子进程、独立音频路由和多会话长期切换的边界需单独核对；原生浮层和轻量增强浮层的外观须以实际系统截图确认。
