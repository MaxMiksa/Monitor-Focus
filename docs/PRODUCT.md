# 产品说明

## 定位

Monitors Focus 是面向个人使用、兼顾开源分享的 Windows 显示器控制中心。常驻核心负责硬件与自动策略，界面按需打开，关闭面板后计划、专注和已开启的边缘滚轮仍继续运行。

公开基线为 v2.0.0。当前工作区包含发布后的改进，公开下载包不包含这些改动。

## 使用范围

- 支持 Windows 10 / 11 x64。
- 当前主要验收环境是一块 AOC U27G4 外接屏和一块 BOE 笔记本内屏。
- 亮度同时支持 DDC/CI 外接屏与 WMI 内屏。
- 控制中心统一使用逐屏软件 Gamma 调色，支持兼容驱动下的外接屏和笔记本内屏；不与硬件 RGB 调色叠加。
- 首版针对 SDR 日常使用，不提供 HDR 色温或 ICC 色彩管理。
- 不提供应用快捷键或场景快捷键；暂停和恢复通过面板或托盘完成。

## 核心状态

产品区分以下概念：

| 状态 | 含义 |
| --- | --- |
| 正常目标 | 面板、场景或计划希望显示器达到的亮度和色温 |
| 手动保持 | 用户手动调节后，在下一计划节点前保持的目标 |
| 场景 | 保存逐屏目标及绑定、专注规则的可复用组合 |
| 时间计划 | 在指定时间触发场景，并按设定时长渐变到目标 |
| 专注遮罩 | 鼠标离开受控副屏后显示的覆盖层，不改变硬件亮度 |

面板显示的百分比表示正常亮度目标。硬件错误会单独提示；目标、写入中和硬件读回的完整区分仍待后续完善。

## 快捷面板

快捷面板承担日常调节：

- 每块屏幕独立显示亮度滑条和目标百分比。
- 支持色温调节的屏幕在对应亮度下方显示色温滑条；没有能力时隐藏该行。
- 亮度联动通过连接／断开图标切换。已校准的设备对按分段曲线双向同步，允许外屏 0% 对应内屏非零亮度；未校准设备保留原有比例绑定及非零基准要求。
- 本机 AOC/BOE 暂将 6500 K 的匹配曲线用于所有色温，外屏超过 95% 时内屏保持 100%。暖色下尚未测得新的匹配曲线，不承诺实际观感始终等亮。调内屏到 100% 时，外屏若已处于 95–100% 则保留当前值；内屏低于 25% 时外屏停在 0%，允许内屏继续单独调暗。
- 开启联动时以外屏当前亮度对齐内屏；联动场景及计划渐变先求外屏目标，再计算内屏目标。解除联动后，逐屏目标独立生效；设备离线不会将其曲线套用到其他屏幕。
- 场景以快捷键风格入口排列，顺序与设置页一致。
- 来源区区分手动场景与时间计划，并允许恢复计划或恢复原色。
- 专注可从面板或托盘暂停、恢复。

手动调整亮度和色温立即生效。手动目标会覆盖自动调节，直到下一个计划节点；实时到达节点时，渐变从当前手动目标继续，而不是跳回旧目标。

## 屏幕边缘滚轮

- 通用设置提供“顶部滚轮调节亮度”和“底部滚轮调节音量”两个独立开关，默认关闭，保存后生效；关闭面板仍可使用。
- 鼠标位于任一屏幕最顶部或最底部的一行像素时，上滚增加、下滚减少，每格 2 个百分点，限制在 0–100%。高精度滚轮累积到一格后调整。
- 顶部调整鼠标所在屏的正常亮度，遵循已有亮度联动、校准、色温补光与手动保持规则；不支持亮度的屏幕不接管顶部滚轮。
- 底部调整当前默认播放设备的系统主音量，不改变静音状态；切换音频输出后使用新的默认设备。
- 按住增强调节按键时，顶部每格将鼠标所在屏的色温提高／降低 100 K（2700–6500 K，上滚更冷）；开启亮度联动时同步支持调色的屏幕。底部每格只调前台窗口所属软件的音频会话 2%，含同一应用进程树内的浏览器音频进程，保留静音；没有可控会话则提示，不改系统总音量。两项分别随顶部／底部原有开关启停。默认 Alt，可在“设置 → 通用 → 色温／应用音量按键”选择 Alt、Ctrl 或 Shift，保存后生效；旧配置缺少此项时采用 Alt。
- 滚轮调节完成后唤起 Windows 原生亮度／音量浮层；亮度浮层按用户选择显示系统内屏背光，外屏亮度和校准后的正常亮度不映射到该数值。系统决定位置、样式、数值和消失时间。
- 仅接管无修饰键或只按已选按键、且无鼠标按键的真实垂直滚轮；未选按键、Win 及组合键（包括 AltGr）放行。离开边缘、功能关闭或后台会话时正常滚动。触发后不再滚动下方窗口。余量在换屏、换边缘、切换增强模式／前台应用或停顿超过 500 ms 后清除；更换按键时清空旧请求和余量。
- 增强模式使用轻量的原生窗口绘制胶囊浮层：色温显示暖→冷进度和 K 值；应用音量显示进程名称、进度和一个百分比，含义与 Windows 音量合成器的应用音量一致，调到 50% 即将当前软件的可控音频会话统一设为 50%，全静音时标记静音。滚轮输入后立即显示目标值，后台异步调整并按实际结果校正；首次进入软件、起始音量未知时先显示“…”等待真实读数，失败隐藏浮层并提示。浮层位于鼠标所在屏幕底部，不抢焦点、不接管鼠标，停滚约 1.5 秒后隐藏。普通模式保留 Windows 原生亮度／音量浮层。
- 软件音量需要软件已建立可控的共享音频会话；独占音频、归属不明确的共享进程会话及仅由其他宿主代播的窗口不保证支持。鼠标位置不决定软件目标，前台窗口才决定；处理中焦点改变则停止旧请求。

## 逐屏色温

- 控制中心通过每块屏幕对应的 Gamma 表调色，不要求显示器支持 DDC/CI 色温；实际支持以驱动和写入验证为准。
- 调色前保存当前颜色表；“恢复原色”、重新检测和正常退出时恢复本应用仍持有的调整。其他程序已经改变颜色时保留其新设置。
- 2700–6500 K 是近似冷暖标尺，不是仪器测量值。较暖端会按 Windows 默认允许的 Gamma 范围压缩，避免请求被系统静默拒绝，不修改系统颜色范围限制。
- HDR、高级颜色、复制显示或无法确认显示映射时停用此路径。与夜间模式、游戏和其他调色软件同时使用可能冲突；检测到外部颜色变化时停止调色并提示重新检测，不持续抢写。
- 写入后读取颜色表验证；拒绝或读回不符时报告失败并尝试恢复，亮度仍可独立调节。颜色表验证不能代替真实画面的观察。
- 色温变暖会降低画面白色亮度。完成校准的笔记本内屏可按目标亮度与色温自动补偿背光；主屏和其他外接屏不补光。界面亮度仍表示用户目标，补光不回写亮度滑条或比例权重，夜间变暗仍由亮度计划决定。
- 内屏以日常、偏暗两档亮度和两个暖度的四个主观匹配点建立曲线，校准范围内插值。超出亮度参照范围时使用边界补偿量的保守延伸，不保证完整范围或仪器级恒亮；显示模式、色彩配置或面板设置改变后需重新校准。
- 内屏背光达到 100% 时提示无法完全补偿，不调整主屏或减弱用户所选暖度。恢复原色、色温应用失败和正常退出时撤回补光；未经校准、身份不明或不支持调色时不启用补偿。
- 跨屏亮度曲线与内屏色温补光独立保存。当前本机只启用跨屏曲线，未完成暖色观感校准前不启用额外补光；主屏始终不补光。
- 温度命令可以只作用于指定设备；省略设备标识时保留旧版对全部支持屏幕调色的兼容行为。
- 原硬件 RGB 实现保留作兼容代码，控制中心默认不启用。

## 场景

场景保存以下内容：

- 每块屏幕的正常亮度和色温。
- 亮度联动开关及逐屏比例权重；设备匹配曲线独立于场景保存。
- 专注开关和受控副屏选择。

规则约定：

- 默认控制全部副屏，也可以指定副屏。主屏始终排除。
- 受控列表为空表示不控制任何副屏；空选择会保存，不会被解释为“全部”。
- 离线设备的目标、比例和受控标识按稳定设备标识保留，不映射到其他屏幕。
- 手动切换和计划节点使用同一套场景行为。
- 旧场景缺少行为字段时，继承加载时的当前规则；读取不会改写用户文件。
- 新场景捕获当前正常目标和当前规则，不保存临时专注遮罩状态。

当前工作区的场景页只编辑名称和逐屏目标，不展示绑定、专注及受控副屏编辑区。已有规则继续保留，新场景仍捕获当前规则。

场景支持拖动排序和键盘移动。点击“保存”后才持久化，场景顺序同步到快捷面板；单纯排序不会重播计划。被时间计划引用的场景不能删除，原因通过按钮悬停提示。

场景页底栏提供撤销、重做、“重置”和“保存”。重置恢复上次保存的共享设置并可撤销；保存成功后清空历史，保存失败保留草稿和历史。

## 每日计划

每个计划节点包含时间、场景和渐变时长：

- 到达节点后应用场景中的绑定、专注和受控屏规则。
- 亮度与色温按 `smoothstep` 缓入缓出，而不是在节点处瞬间跳变。
- 新节点默认渐变 30 分钟，0 分钟立即切换，终点不能越过下一个节点。
- 跨午夜连续计算；休眠或启动时错过节点，直接按当前时间求值，不补播历史步骤。
- 计划持续渐变期间不反复重置专注计时。
- 保存语言、当前专注状态或场景名称等无关设置，不会重播节点规则，也不会清除手动保持。
- 修改实际计划或其引用的场景会重新应用相关规则。

时间点可以拖动排序，也可聚焦手柄后使用上下方向键移动。时间、场景和渐变时长作为一整行移动；执行仍按填写的时间，排序本身不重播计划。

## 专注

专注目标是最多两块屏中的副屏；主屏永不被遮罩。

- 鼠标离开受控副屏达到设定时间后显示遮罩。
- 鼠标返回、手动暂停或满足全屏例外时隐藏遮罩。
- 专注只控制遮罩，不降低硬件亮度。
- 开启或关闭专注、暂停或恢复不会覆盖正常亮度目标。
- 场景切换会重新计算专注等待时间；计划渐变过程中不会每秒重置计时。

### 副屏全屏或最大化时保持亮屏

该选项默认开启，独立于当前前台窗口：

- 受控副屏上存在可见的全屏或最大化窗口时，隐藏该屏的专注遮罩。
- 检测所有顶层窗口，所以拖入、快捷键移入或切回主屏操作都能保持副屏可用。
- 最小化、隐藏、位于其他虚拟桌面或属于本应用遮罩的窗口不算占用。
- 最后一个符合条件的窗口还原、最小化、关闭或移走后，从结束时刻重新计算完整等待时间。
- 此选项只影响专注遮罩，不修改 Windows 的睡眠或电源超时。

## 语言

- 支持简体中文、English 和跟随系统。
- 切换语言立即预览，但不重建当前编辑草稿。
- 保存后，面板和托盘同步使用新语言，无需重启。
- 系统界面使用中文（含繁体系统语言）时显示简体中文，其他语言回退 English。
- 新默认场景名称随语言变化；用户改名后及已有自定义名称保持原样。
- 旧配置缺少语言字段时跟随系统；首次从 v1 迁移时继承旧版语言选择。

## 设置与失败恢复

- 设置页之间共享草稿；切换页面保留未保存内容，回到内容顶部。
- 保存失败时保留草稿，不刷新成“成功”状态。
- 配置保存带 Revision 检查；其他操作已经修改配置时，旧草稿会提示冲突，不能覆盖新设置。
- 硬件部分失败、检测中、离线或核心断开时，界面显示真实状态；不能把失败显示为成功。
- 重新检测会按稳定设备标识保留本次会话的色温目标。设备恢复后重新应用，离线目标保留到核心退出。
- 退出控制中心时移除专注遮罩并恢复原色，保留最新正常亮度。

## 启动与兼容

- 登录自启只保留一条 `MonitorsFocus` 条目，指向自包含包中的 `core/MonitorsFocus.exe --center --background`。
- 关闭面板只退出 `MonitorsFocus.WebHost`，常驻核心继续运行。
- 再次打开面板会连接现有核心，不重复持有设备。
- 不带 `--center` 启动仍进入 v1 的鼠标跟随遮罩模式，保留原有调光行为，仅用于兼容。
- v1 配置首次迁移前先备份；读取或迁移失败时，不修改已有登录自启。

## 已知边界

- 真实比例写入、硬件恢复、休眠重连、混合 DPI 和长时间运行仍需实机验收。
- 当前界面没有完整区分“目标值、写入中、硬件读回”，百分比表示目标。
- 当前场景页精简已进入本机运行包，尚未完成交互复验。
- 用户反馈笔记本内屏轻微偏绿，发生条件与修正量待校准；后续检查独立的绿／品红校正，当前没有自动修改颜色通道。
- `Files/` 是历史本地资料，不代表当前产品行为。

验收状态以[验收说明](ACCEPTANCE.md)为准；技术实现见[开发文档](DEVELOPMENT.md)。

## 前台屏幕与后台桌面隔离

亮度、色温与自动恢复仅面向前台物理控制台会话中已确认身份的实体屏幕，不向后台 RDP 桌面发送控制。暖色被重置回已保存的原色基线时约 3 秒自动恢复；其他程序写入未知颜色时停止调色并提示冲突。会话或设备身份变化时停止写入，等待重新检测。后台视觉识别画面的像素隔离须经实机验证，不能由前台读回成功替代。
