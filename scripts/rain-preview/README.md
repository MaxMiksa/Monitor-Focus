# 雨景选型预览

仅用于浏览器选型，不进入软件正式包，不接天气、定位或硬件。

在本目录运行 `npm ci --ignore-scripts`，然后 `npm start`，访问 http://127.0.0.1:5194。
场景直接使用现有本地资源；比较 tsParticles 和 three.quarks 的不同雨景配置，而非声称每个预设是独立组件。切换销毁旧效果；同一时间只运行一个。强度统一为 0–100，后续可由天气降雨量驱动，当前仅手动。

来源与许可证：

- tsParticles 4.5.3，MIT：https://github.com/tsparticles/tsparticles
- three.quarks 0.17.1，MIT：https://github.com/Alchemist0823/three.quarks
- Three.js 0.187.0，MIT：https://github.com/mrdoob/three.js

页面呈现帧率与粒子数量，不把 JS 堆或纹理数误称为软件总内存。最终选定后需在原生面板重新比较开销。

第 06 款「小乌云淋雨」按已批准示意加入：云宽略大于电脑，轻浮、局部降雨、机顶碰撞后喷溅。雨与两类水花由 three.quarks 驱动，共用一个局部画布，按源图坐标对齐四时段背景；30 fps、DPR 1，雨滴／飞溅水珠／水冠分别上限 320／128／32，不为每次碰撞新建系统。雨量为零清空并隐藏云，暂停／隐藏停止动画，切换释放上下文、纹理、位图和计时器。预览保持完整背景，纯净观景可放大查看。

`raincloud.png` 为依据用户批准概念用 imagegen 生成的透明乌云素材（仅云、无雨／电脑／文字），运行时缩为 512px 宽；不是逐帧图集。浏览器已检查碰撞／水花、零雨量、暂停／恢复、原景对照、四背景、纯净观景与组件切换；本轮未测原生总内存。

雨量曲线为 `180s + 540s³`（s 为 0–1），最大 720 滴／秒，是初版四倍，保留低端细雨；水花数量上限不随雨量增加。云图用内置 imagegen 编辑，提示为「保留云形与光照，清除黑色抠图边及散落杂色，轮廓半透明渐隐，背景真正透明，无新增元素」；沿用 `raincloud.png`。加载禁用预乘 alpha，并在云材质上收紧／渐隐边缘，避免黑色晕边，不增加纹理。浏览器实测最大档约 289 在场雨滴、小雨约 13，归零清空；这不是原生内存测量。
