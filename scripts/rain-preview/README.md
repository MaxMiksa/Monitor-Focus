# 雨景选型预览

浏览器比较页不进入正式包，不接天气、定位或硬件；选定斜风雨与正式软件共用运行时。

在本目录运行 `npm ci --ignore-scripts`，再运行 `npm run build:ui`、`npm start`，访问 http://127.0.0.1:5194。
场景直接使用现有本地资源；比较 tsParticles 和 three.quarks 的不同雨景配置，而非声称每个预设是独立组件。切换销毁旧效果；同一时间只运行一个。强度统一为 0–100，正式软件由天气降雨量驱动，比较页仅手动，正式软件已由天气降雨量自动驱动。

当前选定方向为第 05 款「斜风雨」，默认打开此款。`wind-rain.js` re-export `frontend/src/lib/wind-rain-runtime.js`，保留原有三层风雨的颜色／尺寸／速度，高端以立方曲线增加密度，最大 1380 滴／秒（初版 345 的四倍），新增雨量主要分配到远层。仅用一个 WebGL 画布、三张微型纹理、DPR 1、30 fps；雨滴／水珠／短弧上限 2400／144／24。雨滴投影到同一 cover 背景的源图坐标，只在雨滴经过机顶时触发少量可见的顺风弹落水珠与少量短弧；雨滴轨迹与寿命保持不变，不做雨水阻挡，不在草坡生成水花，不绘制大型水冠或积水圆环。复用单个水珠系统与发射描述，切换时释放全部资源。

「溅落动效」可开关对比；零雨量清空，暂停停止推进，变更视口清空旧落点后重新定位。已验证机顶触发、溅落开关、暂停、雨量归零、低／高强度与画布切换。用户确认后已更新正式版；尚未测新版雨开／关原生内存增量。

水珠按背景像素换算大小和弹起速度，避免远层水花缩得不可见：直径 4–7 源图像素、存活 0.30–0.44 秒；短弧宽 20–30 源图像素、存活 0.20–0.28 秒。三个雨层共享同一落点尺寸，水珠／短弧系统复用，开关、归零与卸载一并清理。

「雨天氛围」默认开启，仅用于斜风雨：复用现有 atmosphere 层，用静态半透明渐变压暗天空、加入适中冷灰色调与克制远雾，避免前景被浓雾泛白；随雨量增强，夜景减轻压暗。无 blur／filter、额外画布／纹理／计时器，不使用全屏模糊。开关、原景对照与零雨量立即撤除；仅改变预览画面，不影响显示器亮度／色温。已检查开关、归零、原景及夜景分支，截图见 `build/diagnostics/rain-gallery/rainy-mood.jpg`；未测原生总内存。

乌云整体不透明度为 80%，在现有边缘渐隐之上轻透出天空；仅修改材质透明度，不新增资源。

第 06 款「小乌云淋雨」按已批准示意加入：云宽略大于电脑，轻浮、局部降雨、机顶碰撞后喷溅。雨与两类水花由 three.quarks 驱动，共用一个局部画布，按源图坐标对齐四时段背景；30 fps、DPR 1，雨滴／飞溅水珠／水冠分别上限 320／128／32，不为每次碰撞新建系统。雨量为零清空并隐藏云，暂停／隐藏停止动画，切换释放上下文、纹理、位图和计时器。预览保持完整背景，纯净观景可放大查看。

`raincloud.png` 为依据用户批准概念用 imagegen 生成的透明乌云素材（仅云、无雨／电脑／文字），运行时缩为 512px 宽；不是逐帧图集。浏览器已检查碰撞／水花、零雨量、暂停／恢复、原景对照、四背景、纯净观景与组件切换；本轮未测原生总内存。

雨量曲线为 `180s + 540s³`（s 为 0–1），最大 720 滴／秒，是初版四倍，保留低端细雨；水花数量上限不随雨量增加。云图用内置 imagegen 编辑，提示为「保留云形与光照，清除黑色抠图边及散落杂色，轮廓半透明渐隐，背景真正透明，无新增元素」；沿用 `raincloud.png`。加载禁用预乘 alpha，并在云材质上收紧／渐隐边缘，避免黑色晕边，不增加纹理。浏览器实测最大档约 289 在场雨滴、小雨约 13，归零清空；这不是原生内存测量。


默认「实际界面」复用当前 React 设置页／场景栏，通过 `?preview=1` 模拟桥操作，不调用真实硬件。构建产物为 `build/rain-ui-preview`；iframe 背景／雨组件替换为空，避免重复渲染。雨层在实际控件上方，水花跟随形变外框上缘，设置展开立即关闭并清除机顶水花，收起恢复；暂停状态同样即时清除。`/product/?preview=1` 可验证正式 `frontend/dist` 资源，需先完成前端构建。开发服务只读挂载这些输出目录，不进入正式产品。

小雨氛围透明度采用雨量的 0.65 次幂渐入，最大值保持，夜景减轻；与正式软件共用 `rain-appearance.ts`。原生五轮面板释放结果见 `build/diagnostics/rain-wind-20261116.json`；不把粒子数或 JS 堆当作软件总内存。
