# 二维天气与天空对照

仅供本地比较。复用实际首页、原图、控件、遮罩和尺寸规则，只在预览构建中替换雨和天空；不改变正式包或硬件行为。

- **天空**：云复用原来的贴图、72 个云片、位置布局、遮罩及移动规则。稀疏／密集星空以固定视角预投影，只绘制可见点并独立闪烁。旧版薄云仍按需加载原算法。
- **雨**：三层均在屏幕平面模拟，沿两种机顶和设置框的实际边缘检测碰撞。纯 Canvas 逐滴绘制和轻量 WebGL 批画共享同一模拟；批画只提交一个点精灵批次，无三维相机、深度缓冲、场景树或粒子库。
- **不变**：单机器背景原有的逐像素换光与飞絮、双机器背景原图及页面交互。

## 查看

在仓库根目录运行，前端依赖沿用项目锁文件。默认是纯 Canvas 雨景；FLAT_BATCH 为 1 时是推荐的批画版本。

```powershell
$env:FLAT_BATCH = '1'
node frontend/node_modules/vite/bin/vite.js build --config scripts/rain-preview/canvas2d/vite.config.js
node frontend/node_modules/vite/bin/vite.js preview --config scripts/rain-preview/canvas2d/vite.config.js --host 127.0.0.1 --port 5196 --strictPort
```

打开[预览首页](http://127.0.0.1:5196/?preview=1)。通用 → 天气雨景 → 启用 → 预览；天空设置可切换云和星。此浏览器入口不控制硬件。切换画法前先停止服务，重新构建、启动。对照正式画面请用相同背景、场景、雨量、窗口尺寸与缩放。

## 实测与边界

同一 Wails 模拟核心和 WebView2，1168×657 DIP、DPR 1.5。固定中午或夜间、云或雨或密集星空，按版本交替启动，每条件每版两次。使用隔离配置；测量包含核心及其后代进程，CPU 以单核为 100%。短测不代表长期值；不同组的基线不可直接相减。原始数据与摘要位于本机 build/diagnostics/flat-effects/。

默认流云从 185.5 降到 177.7 MiB，约 18 fps 不变；密集星空从 191.7 降到 186.6 MiB，约 18 fps 不变，但 CPU 从 24.6% 到 27.1%。单独下雨时，纯 Canvas 维持约 29 fps，但 CPU 从 16.3% 到 20.7%；二维批画独立对照为 184.4 → 174.7 MiB、19.1% → 15.9%、29.3 → 29.8 fps。默认云和批画雨同时启用：211.1 → 194.6 MiB、23.6% → 23.5%、29.6 → 29.5 雨帧/秒。

已观察双机顶命中、展开设置关闭机顶水花、停用后移除画布、以减少动态效果启动时不挂载雨层、旧版薄云可回退；普通云和批画雨同时运行不请求 Three.js。没有证明视觉完全等价，未全面验证云彩配置组合、长期耗电、运行中切换系统减少动态效果或显卡上下文丢失恢复。正式替换前须确认观感、偏好切换过程连续性及回退路径。
